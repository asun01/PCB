# Asun Vision Platform — PCB Repository

Engineering repository for the PCB/PCBA multi-product vision inspection and quality-control platform.

Architecture baseline: ARCH-PCBA-VISION-001 v0.5.3 (candidate / DocMapped).
Development Standard: v2.1.5.
Technology target: C# + .NET 10 + WPF + DevExpress 25.2.3 + HALCON 25.11 where explicitly verified by the active implementation baseline.
AsunImage is excluded from the current implementation baseline.
Hardware-vendor SDKs are outside the current implementation scope; use stable ports/adapters and simulation boundaries only.

Current phase: Phase 1 automated implementation.
Production FunctionSpec implementation remains subject to the recorded Contract/Authority/Environment gates.

Read AGENTS.md and CURRENT_BASELINE.md before implementation.
